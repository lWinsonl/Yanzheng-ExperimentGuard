# 研证代码架构与实现边界

更新于 2026-11-02。本文以源码和隔离测试为依据；见[最新回归](../evaluation/reports/2026-11-02-grounded/summary.md)、[真实模型回放](../evaluation/reports/grounded-case-replay-2026-11-02/summary.md)；历史基线保持原样。

## 前端与部署

React 五步工作流：确定范围 → 收集材料 → 确认事实 → 审查报告 → 修改复查。前端使用同源 `/api`；本地 Vite 转发到 Python 后端，生产容器由 FastAPI 同时提供前端和 API。静态页面本身不能完成上传与审查。

会话和步骤保存在 localStorage，恢复时核验后端会话；非法步骤和损坏存储回退到创建页。组件按会话隔离状态，异步加载有取消保护；迁移回答与参考反馈从后端恢复。页面依据可用宽度排列，实际浏览器测试覆盖 390、768、1440 像素的关键流程，未据此声称所有设备均已验收。

## 材料与事实

1. 上传接口校验计划/执行角色、追加/替换模式、扩展名和大小。
2. 解析文本、源码、Notebook、文本 PDF、DOCX 正文/表格、XLSX 单元格。Office 解析器只读 ZIP/XML，限制解压大小、部件数量和单元格规模，不执行公式；不完整内容明确提示。
3. 规则提取候选事实，模型在可用时补充；每条事实保留材料 ID、字符区间和原文切片。
4. 原文校验通过后，事实仍须用户确认、纠正或拒绝。普通审查只使用已确认/纠正事实。
5. 解释性纠正不等于新的独立证据。实体列表与完整数值记录的自动核对还要求内容与已上传、可验证的执行原文一致；追问回答、计划、代码示例不能替代实际运行记录。

替换前先验证新文件，失败不移除原材料。成功替换会移除该角色的当前材料和事实并重置衍生数据；历史原文归档保留，供旧报告溯源。归档不是可一键回滚的版本管理。

## 规则与模型

基础规则分别处理数据模型实验的划分、泛化、基线、指标与重复运行，以及算法系统实验的基线、指标、稳定性与材料完整性。两个类型均注册限定数值比较/稳定性规则。

`numeric_evidence` 从经确认的完整 JSON 或明确列名 CSV/表格读取观察记录，核对方法、主张指标、指标方向、有限数值、条件声明和结论范围。可比较点估计和所报告样本标准差；提供逐次运行数据时重算均值与样本标准差。条件不足、指标不匹配、未知指标、相互冲突或超出范围时保留未知。详见[数值材料格式](numeric-results.md)。同条件声明和上传内容本身未经过外部真实性验证。

模型辅助方向分析、材料缺口、事实提取、追问、深度复核、教学案例、图候选边和迁移反馈。方向/追问等允许启发式回退；有效模型评分缺失时只给自查建议，不输出掌握分数。

深度复核使用review_context生成本轮证据目录和完整确认记录的程序结果。模型只选择已有evidence_id；服务器按ID绑定原文、区间或程序计算，再解析对应检查类型和ID。选中片段的实际区间用于覆盖范围，不把非连续片段写成已阅读前N字符。未配置、调用失败、解析失败、待核实和成功分开处理；复核期间材料改变会废弃旧输出。

program_checks核对实体交集、限定比较/波动，以及明确方向的二分类CSV召回率分母。长编号不必全部送给模型，但完整确认记录仍由程序读取。已通过的同项不能被模型改成失败；无效来源或不符规则的输出不保留修改操作。已知计算问题使用操作与验证约束，其他语义建议仍须人工核对。引用有效不保证推理正确。

## 图、追问与复查

- 主张—证据图使用确定性规则连接证据，模型候选边和人工校准另行保存。图规则版本升级会重建旧图。
- 追问排序使用手工设定的严重度、不确定性、改变概率和回答成本。EIV 是启发式排序，未校准为真实概率。回答转为独立的待确认材料，经裁决后再审查。
- 每份新报告保存完整确认事实、主张和材料来源快照，并记录成功/失败的检查规则。历史快照不随当前事实或材料修改。
- 发现按规则、主张与明确作用范围配对，可变证据类别不作为身份。配对不唯一、规则未成功执行、主张被删除、事实撤回或旧版缺快照时保留不确定，不能只凭发现消失就称已解决。旧复查接口复用同一算法。
- 修改理由只对照可观察的事实类别变化，不能证明修改有益或实验已正确；同内容重传不视为变化。
- 每份报告保存程序检查。版本差异中的repair_checks重查原失败项，区分仍未通过、当前通过但范围待确认、同声明范围提供记录通过和未验证。缺记录、换范围或配对歧义不能算修复；evaluation_scope是上传者声明，不是来源认证。旧报告缺程序快照须重新建立基准。

## 存储与资源

会话聚合保存在内存并以临时文件替换写入 JSON，启动时恢复。浏览器 HttpOnly Cookie 决定会话归属，其他浏览器不能枚举原会话；它不是实名账号或班级协作。

演示版有单文件、文本、写操作与模型尝试额度。额度是单进程计数，重启会重置；JSON 存储没有数据库事务和多进程协调，写入失败的用户提示仍需加强。免费云端容器没有持久磁盘时，重启或重新部署可能丢失会话。

## 仍需验证的部分

本轮完成隔离回归、开发探针、本地浏览器与小规模真实智谱回放。复杂编码语义仍有漏检，模型会把一般文档提醒写成风险；来源绑定成功不是质量证明。正式同模型比较、教师留出集、学生教学实验、生产冷启动和跨进程并发仍未验证。

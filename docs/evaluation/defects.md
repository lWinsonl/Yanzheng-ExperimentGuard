## 同时补齐的能力与界面问题

- 完整数值记录可核对固定条件点估计和样本标准差；未知指标、方法/指标不符、不同条件、NaN、假布尔数值、过宽主张等仍拒绝确定判断。
- 前端原有 10 条 effect/依赖警告消除，静态检查启用警告即失败。
- 相同数量材料替换后重新刷新缺口；异步加载避免串入旧会话；迁移回答与反馈在刷新后恢复。
- 添加真实浏览器回归，覆盖三种宽度、核心工作流、损坏本地状态、失败替换后重试与模板下载。详见[浏览器验收记录](browser-acceptance.md)。

## 复核

仓库根目录执行：

```text
python -m evaluation.run --release-gate --browser
```

运行器关闭真实模型，使用临时数据目录和本机浏览器隔离上下文。历史 XFAIL 日志不删除、不改写；它们记录的是修复前版本，不能用来判断当前状态。

## 没有被本轮证明的能力

真实模型语义准确性、供应商实际 429/超时、生产冷启动、断网恢复、跨进程写入、真实课程材料和学生学习效果仍待验证。模拟错误测试不能代替供应商实测，开发探针满分不能代替教师留出集。

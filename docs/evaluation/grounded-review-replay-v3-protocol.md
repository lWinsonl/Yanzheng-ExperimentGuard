# 第二次实现修订后的开发回归

本轮是对已见开发材料的第二次实现修订，不是新增独立试验或未知留出集。第一次ID协议回放结果完整保留在 `evaluation/runs/grounded-case-replay-2026-11-02/`，其调用时源码另有ZIP归档。

修订原因：模型会把合法证据绑定到自造的check_id、错误的问题分类，或直接复制枚举选项字符串。现在模型只选择证据ID；服务器从程序证据解析检查ID及类型，不能让模型覆盖已通过的计算。对于已有明确程序失败的项，操作与验证使用程序约束：同源分组后重查交集、零分母标为不可估计、不得通过减半复制或改标签冒充修复。其他语义建议仍须人工核对。

调用前重新冻结后端源码指纹、提示词、本协议；沿用首次6份输入及原金标字节，原记录不覆盖。仍用同一glm-4-flash，每份一次，最多6次真实请求、2500输出tokens、网络超时参数45秒、无重试；本轮实现迭代合计最多12次请求。不得因为结果不好而重复请求挑选输出。

与前轮共同报告：供应商返回/解析/绑定是否成功、接受与拒绝条目、逐项语义复核、实际修复验证；不只挑第二次较好的数值宣传。既有程序结果通过与证据绑定率不等于模型语义判断正确。两次运行的耗时和tokens变化受提示词、输出长度、服务状态影响，不做因果归因。

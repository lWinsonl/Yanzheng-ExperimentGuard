# 真实材料可行性试跑：预定协议

日期：2026-11-02。被测应用冻结为 `a56fad86f26581fb82aeacef638482f81999dc77`，本轮不根据输出修改产品或重写金标。目标是检验实际用途并发现失败边界，不估计总体准确率或教学效果。

## 材料与目标

| 编号 | 材料来源 | 唯一目标判断 |
| --- | --- | --- |
| R1 | Beger 等公开的 Blair–Sambanis 复现包原始评分脚本、数据编码说明、混淆矩阵 | 缺失值代表持续内战，把它改为正类会使 onset（新发生）目标变成 incidence（存在）评分；应指出目标不一致 |
| R2 | 同一复现包按 onset 评分的代码片段与结果 | 不应继续指控同一种“NA改为正类”的目标替换；不要求宣称整个研究正确 |
| R3 | 同一复现包固定表中 Assuming Persistence 分支、实际正类为零 | 不能从这份表估计 onset recall；应说明分母为零，不可把准确率当作召回率 |
| D1 | scikit-learn 自带真实手写数字数据，先重复图片再按行随机划分；实际训练 1-NN、导出编号 | 原始图片编号存在交集，应识别该测试不能证明对未见原始图片的泛化 |
| D2 | 同一数据、同一模型、按原始图片组划分；实际训练和编号 | 所提供完整编号无交集；不能只见“随机”字样就指控同源图片泄漏，也不能外推到其他泄漏均不存在 |
| D3 | D1 的实际 accuracy 结果，但不提供代码或划分编号 | 不足以判断是否同源隔离，须要求代码/编号，不能凭高分证明或断定泄漏 |

R1–R3 属于一个真实科研复现项目的关联输入，不能算三个独立研究；D1–D3 是真实数据上的受控故障注入与对照，不是发现了三篇论文的问题。三个预定随机种子为 41、42、43，只用于观察训练结果，不能算独立项目。

原研究评分争议只核查具体代码和表格，不评价作者动机或据此否定论文全部结论。复现包维护者的分析不是独立教师金标；本轮开发者核对来源，后续需教师盲评。

## 执行与成本

先保存输入、来源URL/固定提交/文件哈希、程序运行结果和目标标签，再调用研证。直接读取公开数据，不执行下载的第三方代码；内战案例仅重算小型评分表，不重新训练其全部模型。数字实验实际运行本地 CPU 训练。

1. 规则提取、原文锚点核验与确认、普通审查、主张—证据图：全部6份输入。
2. 使用已有配置的 `glm-4-flash` 做深度复核：每份输入一次，最多6次，不因输出不好而重试。
3. R1 与 D1 另做相同材料、相同深度复核提示词、无规则发现上下文的直接模型参照，各一次；这是定位增益的小规模参照，不是足够的正式基线比较。

最多8次真实供应商请求，每次最多3000输出tokens、45秒，无自动重试。记录实际usage、失败和输入覆盖，金额未知时不声称免费。规则阶段暂不调用模型事实提取；事实确认由脚本保存并由开发者对照原文复核，未测真实学生确认成本。

模型只接收公开案例材料、对应主张和允许的规则发现，不接收目标标签、复现作者的错误结论段落、评分标准或本轮结果。真实会话目录、线上站点、个人学生材料和密钥不进入实验输出。

## 评价

按预定的目标判断逐项人工复核：是否检出、是否有正确原文引用、推理是否成立、建议是否针对且可验证。正确保留不确定性也算合理；无输出、超时、解析失败单列技术失败，不能算正确的信息不足。不把普通规则产生的其他缺口自动当目标检出。

保留所有原始输出；不删失败、不挑最佳seed、不用同一模型给自己打分。检查模型所引原文是否位于实际送入的范围；字符引用真实不等于推理成立。数据编码说明是开发者按复现包整理的背景，须披露这种人工整理成本。

不报告总体真实准确率、获奖概率或教学效果；只回答这两类材料上哪些用途已跑通、哪些仍需要教师与更完整证据。

# 查看历史会话

页面顶部始终提供“历史会话”按钮，可在上传、确认、审查和复查过程中打开，不需要先清空当前会话。
列表重新读取当前浏览器有权访问的记录，按创建时间从新到旧排列；没有标题的记录显示为“未命名审查”，不再被过滤，也不只展示前十条。
点击记录后先核对其仍可访问，再进入材料页继续。关闭列表或打开失败不会清空当前审查。
没有记录、正在读取和读取失败分别展示，失败时可以重试。

## 记录可见范围与保留

- 历史列表由后端按浏览器凭据隔离，未放开其他浏览器会话的访问权限。
- 更换浏览器、网址或清除浏览器凭据，可能无法再访问原有记录。当前演示版不是账号登录系统。
- 本地服务在自己的数据目录保存 JSON；目录仍存在时可以恢复。
- 当前 Render 免费部署使用 `/tmp/yanzheng-data`。该目录不是持久化数据库；服务重新部署、重启或休眠后，本地记录会丢失。
- 顶部入口只能打开仍存在且当前浏览器有权访问的记录，不能恢复已丢失的原始材料、报告或会话。

需要长期保留时，应另外配置持久化存储。重要结果请及时导出；不能把浏览器记住一个会话编号当成服务端备份。
Render 的行为以[免费实例官方说明](https://render.com/docs/free#local-files-lost-on-redeploy)为准。

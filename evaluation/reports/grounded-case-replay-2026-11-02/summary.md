# 证据绑定与修复验证：实现后的真实回归

日期：2026-11-02。初始应用基线a56fad8，修订后源码指纹见[第一轮清单](manifest-v2.json)和[最终清单](manifest-v3.json)。两轮全部使用首次真实试跑的相同6份输入和原金标字节，输入SHA256均为`e8f621da2b850829bddae5b7a703edb0aaa48bce54d7f95e2cc527fb402d83a9`。没有改产品来伪装未知测试结果：这些是已见开发回归，不能报告真实总体准确率。

## 实现

1. 模型只选已有证据ID，服务器绑定原文、材料、字符区间；程序证据由服务器解析检查类型与ID，不让模型编文件名或检查编号。
2. 已确认的完整记录由程序核对实体交集、限定数值/稳定性、二分类召回率分母。长编号原文即使只提供片段，完整计算结果仍交给模型。无法校验的模型输出仅显示待核实项，不保留修改操作。
3. 已知计算问题的建议使用明确操作与验证约束；没有对应自动检查项的语义建议标为需要人工核对。第五步以新的确认记录重查原失败项，不以“建议写完”“删材料”或“换数据”代替修复。

## 两次实现修订均保留

第一轮仍让模型填写check_id和分类，出现自造编号/复制枚举等问题；随后改为服务器从证据解析类型与检查编号，并为计算问题绑定修复约束。两轮各6次请求，无重试，共12次，保留每轮调用时源码、输入、原始输出和失败，未挑最佳一次重跑。

## 逐项判断

| 输入 | 最终结果与人工复核 |
| --- | --- |
| R1 · 原评分目标编码 | 模型只提出来源/编码一致性的一般疑问，未准确解释NA转1如何把onset评分改为incidence。具体方法错误仍未可靠检出，不能算完成。 |
| R2 · onset口径评分 | 没有重复指控NA转1，但仍把一般文档提醒标为risk；缺乏实质风险依据，说明语义误报边界仍需改进。 |
| R3 · 零实际正类 | 程序明确计算TP+FN=0、recall=null，报告新增明确问题。模型解释成功绑定该计算；操作被限定为不可估计/合法新评估，不允许改标签凑正类。 |
| D1 · 原图重叠 | 程序读取完整记录，交集1235。模型引用程序证据，建议绑定同源分组及新编号交集验证，不再用复制次数减半作为修复。 |
| D2 · 分组后隔离 | 程序交集0；模型仍试图报告相同项风险，但服务器拦截并隐藏修改操作。证明的是拦截机制生效，不是模型已学会判断。 |
| D3 · 只有accuracy | 规则保留信息不足；模型将未知提议为risk，被服务器拦截，未强制学生改实验。 |

R1–R3来自同一个公开科研复现项目；D1–D3来自同一真实数字数据上的受控注错与对照。它们不是6个独立研究。原始来源和实际训练见[首次真实试跑](../real-case-pilot-2026-11-02/summary.md)。本轮没有重训那项科研研究，也没有新增学生或教师盲评。

## 资源与边界

第一轮已报告usage 9451 tokens，最终轮9678 tokens，两轮共19129；费用未核实。没有选用新模型。耗时与token变化同时受提示词、输出长度和供应商状态影响，不据此声称算法加速。

模型事实提取本轮未调用；脚本保存事实确认并由开发者对照原文，未测学生确认准确性与成本。证据ID来自上传原文；程序计算只用已确认且出处相符的完整执行记录。仍未独立验证运行记录真伪、源数据完整性与实际训练过程。

最终离线回归[196项测试、12项浏览器用例通过](../2026-11-02-grounded/summary.md)，前端构建与严格静态检查通过。浏览器包含一项模拟复核响应来检验待核实区，不应与这里的12次真实智谱请求混淆。开发集通过、引用绑定成功都不能代替真实留出集或教学效果研究。
